# SpeedGuard

<p align="center">
  <img src="./assets/speedguard-logo-transparent.png" alt="SpeedGuard icon" width="220" />
</p>

SpeedGuard is an Android app for speed monitoring with configurable alerts:

- voice alert (TTS)
- vibration
- visual overlay
- multiple thresholds with hysteresis and re-alert

## Safety Notice

SpeedGuard is an assistance tool. It does not replace attention to traffic, road rules, or official signage.
