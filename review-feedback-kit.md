# SpeedGuard Review and Feedback Kit

Last updated: 2026-04-21

Use these copy-paste messages for internal testers.

## 1) Tester message (RO)

```text
Salut! Te rog sa testezi ultima versiune SpeedGuard din linkul de internal testing.

Dupa test, trimite-mi feedback scurt in formatul:
1) Telefon + versiune Android
2) Instalare/update din Play a mers? (Da/Nu)
3) Start/Stop monitorizare merge? (Da/Nu)
4) Voice alert merge? (Da/Nu/Partial)
5) Beep mode merge? (Da/Nu/Partial)
6) In masina, prin Bluetooth, alertele se aud? (Da/Nu/Partial)
7) Bug observat (1-2 propozitii)
8) Rating general (1-5)

Mersi!
```

## 2) Tester message (EN)

```text
Hi! Please test the latest SpeedGuard internal build from the Play testing link.

After testing, send short feedback in this format:
1) Phone model + Android version
2) Install/update from Play worked? (Yes/No)
3) Start/Stop monitoring works? (Yes/No)
4) Voice alert works? (Yes/No/Partial)
5) Beep mode works? (Yes/No/Partial)
6) In car, over Bluetooth, are alerts audible? (Yes/No/Partial)
7) Bug observed (1-2 sentences)
8) Overall rating (1-5)

Thank you!
```
