# Support - SpeedGuard

Last updated: 2026-04-14

## Support contact

- Email: `speedguard@111.md`

## Useful info when reporting an issue

Please include:

- phone model and Android version
- SpeedGuard app version
- reproducible steps
- expected behavior vs actual behavior
- screenshots or logs (optional)

## Common issues

### Voice alerts not audible

- Check that voice alert is enabled in app settings.
- Check media volume on the device.
- Check TTS availability in settings diagnostics.

### Monitoring does not start

- Verify location permission.
- Verify notification permission (Android 13+).

### Overlay does not appear

- Enable overlay in app settings.
- Grant "Draw over other apps" permission.
